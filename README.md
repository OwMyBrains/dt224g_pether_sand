### Skillnaden mellan git add och git commit

- add lägger till filer med ändringar som ska publiseras
- commit sparar en snapshot av filen som addats inför nästa push som visar vad som ändrats sedan tidigare commit.

### Branches

- Branches används för att kunna testa/lägga till nya funktioner innan de läggs till i main. Vilket gör att man skapar en arbetskopia och skulle det inte fungera som tänkt påverkas inte mainsidan som redan är publiserad.

### Merge

- Merge lägger till det som skrivits i branchen man vill mergea med main i main filen.

### Pusha till Github och publisera till Netlify

- Pusha till github är att ett sätt att hantera ändringar i nya versioner av ett projekt medan Netlify är en plats där du publiserar själva hemsidan. Netlify läser uftast koden från github och laddar in nya ändringar till den publiserade hemsidan.
